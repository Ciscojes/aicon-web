# SPEC-001 — Visión del producto

## Estado

Aprobada como base provisional.

## Objetivo

Crear una plataforma web para vender casas ya construidas dentro de varios condominios y administrar a los clientes interesados mediante un CRM básico.

## Alcance

- Experiencia pública para compradores.
- Catálogo de condominios y casas.
- Cotizaciones y contacto con asesores.
- Administración autónoma del contenido.
- Seguimiento comercial básico.

## Usuarios

- Visitante o comprador.
- Asesor de ventas.
- Administrador o dueño.

## Requisitos funcionales

- El comprador podrá explorar condominios y casas.
- El comprador podrá solicitar una cotización y contactar a un asesor.
- La constructora podrá administrar su inventario sin intervención técnica.
- La constructora podrá registrar y dar seguimiento a clientes potenciales.

## Criterios de aceptación

- Existe una ruta pública desde la portada hasta el detalle de una casa.
- Desde una casa se puede calcular una estimación y solicitar atención.
- Una solicitud crea un registro relacionado dentro del CRM.
- Un administrador puede actualizar el catálogo desde el panel.
