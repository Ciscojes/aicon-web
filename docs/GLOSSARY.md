# Glosario

- **Administrador:** usuario con control del catálogo, configuración, usuarios y CRM.
- **Asesor:** usuario que atiende clientes y actualiza oportunidades comerciales.
- **Condominio:** proyecto residencial que contiene una o más casas.
- **Modelo:** diseño y características compartidas por una o varias casas.
- **Unidad:** casa específica, identificada por un código o número.
- **Casa de diseño único:** unidad que no comparte un modelo reutilizable con otras casas.
- **Lead o cliente potencial:** persona interesada registrada en el CRM.
- **Oportunidad:** seguimiento comercial que relaciona a un cliente con una casa o condominio.
- **Cotización estimada:** cálculo automático informativo y no vinculante.
- **Cotización formal:** solicitud enviada a un asesor para revisión y respuesta.
- **Prima:** aporte inicial del comprador que reduce el monto por financiar.
- **Avalúo:** valoración de la propiedad realizada por un perito para la entidad bancaria.
- **MVP:** primera versión funcional con el alcance mínimo aprobado.
- **SDD:** desarrollo guiado por especificaciones; primero se acuerda qué debe hacer el producto y luego se implementa.
